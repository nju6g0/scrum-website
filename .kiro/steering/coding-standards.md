# Coding Standards

- Use named exports for reusable components.
- Define explicit prop types using TypeScript.
- Keep components focused on a single responsibility.
- Avoid duplicated UI code.
- Use semantic HTML elements.
- Use Tailwind utility classes.
- Extract repeated class combinations when appropriate.
- Do not use inline styles unless necessary.
- Do not use `any`.
- Do not modify unrelated files.
- Do not install dependencies without explaining why.
