# Product Overview

## Project

EGs F2E - Week 3 Scrum

## Purpose

依照 Figma 設計稿，開發一個
符合設計規範的 Scrum 相關網站。

## Design Reference

https://www.figma.com/design/UE8NpczYv3MaAyDVJCqtRF/EGs-F2E---Week3---Scrum-%E6%96%B0%E6%89%8B%E6%9D%91--Copy-?node-id=1-2&p=f&t=LvB9nEtiSDNrQOJk-0

## Requirements

- 以 Figma 作為 UI/UX 設計依據
- 優先還原設計稿的視覺與互動
- 支援 Responsive Design
- 元件需要具備可重複使用性
- 保持良好的 TypeScript 型別安全
- 避免不必要的複雜化
