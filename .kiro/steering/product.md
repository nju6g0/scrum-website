# Product Overview

## Project Name

EGs F2E - Week 3 Scrum

## Project Purpose

Build a responsive Scrum website based on the provided Figma design.

The project focuses on frontend implementation and interactive user experiences.

## Design Source

Figma:
https://www.figma.com/design/UE8NpczYv3MaAyDVJCqtRF/EGs-F2E---Week3---Scrum-%E6%96%B0%E6%89%8B%E6%9D%91--Copy-?node-id=1-2&p=f&t=LvB9nEtiSDNrQOJk-0

## Product Scope

- Implement the UI based on Figma.
- Implement the interactions shown or implied by the design.
- Use mock data instead of a backend.
- Support responsive layouts.
- Build reusable React components.

## Constraints

- No backend implementation.
- No database.
- No authentication service unless explicitly required by the design.
- No real API integration.
- Do not invent features that are not supported by the design or approved requirements.

## Product Principles

1. Visual consistency with Figma.
2. Functional and intuitive interactions.
3. Reusable component architecture.
4. Maintainable TypeScript code.
5. Responsive user experience.

## Definition of Done

- UI matches the approved design.
- Interactive elements work correctly.
- Mock data is used consistently.
- Responsive layouts are verified.
- TypeScript and ESLint checks pass.
- No unrelated functionality is broken.
